# Priprava na razgovor

Slovenski priročnik za pripravo na razgovor: Oracle Analytics, BI Publisher,
SQL, PL/SQL, podatkovna skladišča, migracija in skrbništvo informacijskih sistemov.

**[Odpri priročnik na GitHub Pages](https://dejanban.github.io/informations/)**

## Datoteke

- [priprava_na_razgovor.html](priprava_na_razgovor.html) — priročnik z iskanjem, temnim načinom in možnostjo tiskanja oziroma shranjevanja v PDF. Za lokalno uporabo ga odpri v brskalniku.
- [ucni_oracle.sql](ucni_oracle.sql) — učni primeri za ločeno učno shemo Oracle.
- [index.html](index.html) — začetna stran, ki samodejno odpre priročnik.

## GitHub Pages

Po objavi datotek v repozitorij v **Settings → Pages** izberi **Deploy from a branch**,
vejo z datotekami in mapo **/ (root)**, nato shrani nastavitev.

GitHub Pages bo na naslovu <https://dejanban.github.io/informations/> odprl
`index.html`, ki obiskovalca preusmeri na `priprava_na_razgovor.html`.
